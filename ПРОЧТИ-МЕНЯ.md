# Дашборд Atlas

## Что это за папка

Здесь находится первая версия внутреннего дашборда Atlas. Реальный маркетинговый план загружается из открытой Google-таблицы, а факт и финансовые разделы пока заполнены согласованными демонстрационными данными.

## Как запустить

1. Запустите Docker Desktop.
2. В PowerShell откройте эту папку.
3. Выполните:

```powershell
docker compose up --build
```

Если установлен старый Docker Compose, используйте эквивалентную команду `docker-compose up --build`.

4. Откройте `http://localhost:3000`.

Остановка: нажмите `Ctrl+C`, затем выполните `docker compose down`. База сохраняется в Docker-томе.

Для разработки без контейнера приложения сначала поднимите PostgreSQL, затем выполните `npm install`, `npm run db:migrate`, `npm run db:seed` и `npm run dev`.

## Если что-то сломалось

Пришлите Codex точный текст ошибки, команду, после которой она появилась, и скриншот экрана. Не удаляйте папку проекта и Docker-том с базой: в них находятся код и история импортов.

Проверить состояние контейнеров можно командой:

```powershell
docker compose ps
```

## Чего лучше не делать

- Не добавляйте пароли и ключи в файлы, которые отправляются в Git.
- Не редактируйте вручную файлы миграций после их применения к рабочей базе.
- Не удаляйте Docker-том базы без резервной копии.
