Итак, мы делаем дашборд компании Atlas, которая занимается маркетингом. Данные придумай сам — правдоподобные, в рублях, с января 2026 по август 2026. Показатели должны быть связаны между собой: клики → визиты → лиды → встречи → КП → договоры → оплаты → выручка → оплата подрядчиков, чтобы воронка сходилась с выручкой.

Дизайн лаконичный, минималистичный.
Для ориентира возьми стиль журнала Economist или газеты Financial Times, только используй приглушённые цвета, не используй красный цвет в гамме, вместо него используй синий

Блоки разделяй тонкими линиями — без рамок, теней и скруглений. Таблицы без полосок: тонкая линия между строками и подсветка строки под курсором. Максимально просторно. Числа с разрядами через пробел.

Шрифт — Montserrat, только он, без второго шрифта.

Минимум подписей в интерфейсе, всё, где применимо — тултипы.
Использование эмодзи недопустимо.

У дашборда будут четыре вкладки.

Единая структура каждой вкладки: сверху строка KPI-карточек, ниже два блока в два столбца (агрегаты слева, динамика справа), внизу таблица-детализация.

1. Маркетинг (план / факт)

Показатели в разрезе направлений:
- виды рекламы
- бюджет
- конверсия в посещение
- CPC, CPL

Нужны KPI-карточки ключевых показателей, прогресс-бары по всем показателям (план / факт) и таблица. Справа — столбики бюджета план/факт по периодам.

2. Выручка

Выручка и зарплата подрядчиков в разрезе направлений. Процент зарплаты от выручки — с подсветкой тёплым цветом, если доля превышает норму.

3. ДДС

KPI-карточки: приход, расход, чистый поток. Пайчарт — диаграмма расходов. Диаграмма динамики выручки.

4. Продажи

Воронка продаж по месяцам:
- лид получен
- встреча проведена
- КП выставлено
- договор подписан
- оплата получена

Рядом с воронкой — динамика этапов по периодам.

Также должны быть фильтры по направлениям (отделам: брендинг, разработка сайтов, видео, контент, SMM, реклама). Фильтры собери в дропдаун с чекбоксами и кнопками «Выбрать все» и «Сбросить все». Если снято последнее направление — вместо контента состояние «выберите хотя бы одно направление».

Для фильтрации периодов сделай удобный компонент Date Picker: стрелки «назад-вперёд» по выбранному периоду, быстрые варианты («этот месяц», «прошлый месяц», «этот квартал», «прошлый квартал», «этот год», «всё время») и сетка месяцев с переключением года, где месяцы вне диапазона данных недоступны.

Динамические показатели должны отображаться в нескольких режимах:
- месяцы
- кварталы
- годы

Всё на экране пересчитывается от выбранного периода, режима и набора направлений — KPI, прогресс-бары, графики, таблицы. Рядом с ключевыми цифрами показывай рост или падение по сравнению с прошлым таким же периодом.

Немного анимации при загрузке и переключении вкладок: блоки плавно появляются, столбики и полосы вырастают, линия графика прорисовывается — с небольшой задержкой друг за другом.

Графики рисуй сам, без сторонних библиотек.
