# Дашборд Atlas — реализация первой версии

## Подготовка

- Сохранить этот план целиком в `ПЛАН.md` в корне репозитория.
- Сохранить существующий дизайн-промт без изменений.
- Создать русскоязычные `ПРОЧТИ-МЕНЯ.md` и `AGENTS.md` с командами запуска и ограничениями проекта.
- Добавить `.gitignore`, безопасный `.env.example` и игнорируемый `.env` для локальных настроек.

## Архитектура и данные

- Создать приложение на Next.js, React и TypeScript с PostgreSQL и Prisma.
- Подготовить Docker Compose с сервисами приложения, фоновой синхронизации и базы данных.
- Реализовать импорт публичной [Google-таблицы](https://docs.google.com/spreadsheets/d/1ln0TpUcOkMdJkZ0ALwtEsLmaWMV7flFYs332Hu_ap2w/edit?usp=sharing) через CSV без Google API.
- При импорте разбирать русские числа, рубли и проценты, игнорировать итоговую строку и атомарно проверять 60 строк: 12 месяцев × 5 направлений.
- Выполнять синхронизацию при первом запуске и далее каждые 30 минут. Ручной и автоматический процессы защищать от одновременного запуска.
- Журналировать каждую попытку; новый снимок создавать только при изменении нормализованных данных. При ошибке сохранять предыдущую успешную версию.
- Хранить в БД пять направлений: Брендинг, Разработка сайтов, Видеоконтент, SMM и Рекламные кампании.
- Создать детерминированные демо-данные за январь–август 2026 года со связанной цепочкой: посещения → лиды → встречи → КП → договоры → оплаты → выручка → подрядчики.
- Использовать точные десятичные значения для денег; конверсии, CPC и CPL рассчитывать из агрегированных исходных величин.

## Интерфейс

- Реализовать вкладки «Маркетинг», «Выручка», «ДДС» и «Продажи».
- Добавить общие фильтры направлений и периода, режимы «Месяцы / Кварталы / Годы», быстрые периоды и сетку месяцев.
- Сохранять выбранные фильтры при переключении вкладок и перезагрузке.
- При снятии всех направлений показывать «Выберите хотя бы одно направление».
- «Маркетинг»: бюджет, посещения, лиды, конверсия, CPC, CPL, прогресс план/факт, столбики по периодам и таблица направлений. Виды рекламы пока не добавлять.
- «Выручка»: выручка, оплата подрядчиков, маржа и доля подрядчиков. Долю выше настраиваемого порога 40% выделять тёплым цветом.
- «ДДС»: приход, расход, чистый поток, диаграмма расходов, динамика поступлений и таблица.
- «Продажи»: KPI, воронка, динамика этапов и детализация по направлениям.
- Показывать план до декабря, факт — до августа. Будущие фактические значения обозначать как отсутствие данных; выполнение считать только по сопоставимым месяцам.
- Добавить кнопку синхронизации в виде иконки с русским тултипом, состояниями загрузки и результатом операции.
- Соблюсти дизайн: Montserrat, приглушённая газетная палитра с синим акцентом, тонкие линии, без теней, скруглений, красного цвета и эмодзи.
- Рисовать графики самостоятельно на SVG, без библиотек. Добавить ненавязчивые анимации с поддержкой `prefers-reduced-motion`.
- Оптимизировать интерфейс для компьютера и планшета; на телефоне перестраивать блоки в одну колонку.

## API и модель хранения

- `GET /api/dashboard/{marketing|revenue|cash-flow|sales}` — данные вкладки с учётом фильтров.
- `GET /api/sync/marketing-plan` — состояние последней синхронизации.
- `POST /api/sync/marketing-plan` — ручная синхронизация.
- Основные сущности: направления, источники, попытки импорта, версии плана, строки маркетингового плана, маркетинговый факт, продажи, расходы подрядчиков и движения денежных средств.
- Предусмотреть общий интерфейс коннекторов, но реализовать только текущую Google-таблицу.
- Хранить секреты только в переменных окружения; в дальнейшем использовать секреты Amvera.
- Использовать часовой пояс `Europe/Astrakhan`.

## Проверка и приёмка

- Покрыть тестами импорт русских чисел, проверку строк, агрегаты, конверсии, будущие периоды и обработку отсутствующих данных.
- Проверить создание версий, отсутствие лишней версии при неизменившемся источнике, сохранение старых данных при ошибке и блокировку параллельных запусков.
- Добавить проверки API и E2E-сценарии вкладок, фильтров, Date Picker и ручной синхронизации.
- Проверить адаптивность, русскоязычный интерфейс, доступность тултипов и отключение анимаций.
- Выполнить чистый запуск через Docker Compose, миграции, заполнение демо-данными, реальную синхронизацию и production-сборку.
